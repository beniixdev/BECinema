# BECinema

Ez egy egyszerű mozi weboldal, ami bemutatja az elérhető filmeket és a foglalásokat. Az oldalon meglehet nézni a filmek adatait, illetve a foglalások táblázatos vagy kártyás nézetben is megjelenik.

A foglalások törölhetőek, de az adat csak az oldal újratöltéséig változik meg.

Használathoz indítsd el az `index.html` fájlt egy helyi webszerveren keresztül.
